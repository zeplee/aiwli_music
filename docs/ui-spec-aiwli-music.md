# Aiwli Music UI 与交互规格

**版本** v1.0 · 2026-10-27
**读者**：接手本项目的 AI 或人类工程师。
**依赖**：[`aiwli-music-design.md`](./aiwli-music-design.md)（架构与接口）、[`adr-aiwli-music.md`](./adr-aiwli-music.md)（决策依据）

> 本文档定义界面结构、导航、状态呈现与交互规则。**凡是标注「依能力位」的地方，必须读 `SourceManifest.capabilities` 决定是否展示（见 ADR-008），不得硬编码假设。**

---

## 1. 信息架构

### 1.1 五端共用导航骨架

移动端（Android/iOS）用底部导航；桌面端（macOS/Windows/Linux）用左侧纵向导航栏。**同一套页面组件，仅容器不同。**

```
移动端（底部 5 tab）        桌面端（左侧栏）
┌──────────────┐          ┌────┬─────────────────┐
│   内容区      │          │ 发现│                 │
│              │          │ 搜索│    内容区        │
├──────────────┤          │ 音乐│                 │
│发现 搜索 音乐 │          │ 下载│                 │
│   我的 设置   │          │ 我的│                 │
└──────────────┘          │ 设置│                 │
                          └────┴─────────────────┘
```

**五个一级页面**：

| 页面 | 职责 | 关键要素 |
|---|---|---|
| 发现 | 榜单、推荐、源入口 | 依能力位显示各源榜单；无榜单能力的源不出现 |
| 搜索 | 关键词搜索 + 源筛选 | 多源聚合扇出（§4.6）；渐进式返回 |
| 音乐 | 歌单、本地库、最近播放 | 歌单增删改；本地扫描入口 |
| 下载 | 下载中 / 已完成 / 失败 | 并发控制、断点续传状态 |
| 我的 | 设置、源管理、关于 | 源管理是重点页（§5） |

**二级页面**（push）：播放器全屏、歌单详情、专辑详情、歌手详情、源详情、源编辑、歌词设置、下载设置、关于/许可。

### 1.2 导航规则
- 移动端：底部 tab 切换不压栈（保留各 tab 独立栈）
- 桌面端：侧栏切换同样保留各栈；`Esc` 返回上一级；播放器全屏用**覆盖层**而非独立路由（避免返回栈污染）
- 迷你播放条：移动端在 tab 之上常驻；桌面端在内容区底部常驻。点击展开全屏播放器

## 2. 播放器界面

### 2.1 全屏播放器布局

```
┌─────────────────────────────┐
│ ←            来源:酷我   ⋮  │  ← 顶部：返回 / 当前源标识 / 更多菜单
│                             │
│      ┌───────────────┐      │
│      │               │      │  ← 封面（可切换方形/圆形，见 §2.4）
│      │    封面        │      │     支持主色提取生成动态主题
│      └───────────────┘      │
│                             │
│  歌曲名                     │
│  歌手 · 专辑                │
│                             │
│  ──────●────────────        │  ← 进度条（可拖动 seek）
│  01:23            03:45     │
│                             │
│   ⤺   ◀   ▶/⏸   ▶   ⤻      │  ← 随机 / 上一首 / 播放暂停 / 下一首 / 循环
│                             │
│  ♪ 歌词  ⚙ 音质  ♡ 收藏     │
└─────────────────────────────┘
```

**歌词区**：点击"歌词"在封面区与歌词区之间切换（同一位置纵向滚动，不新开页）。
- 逐行模式：当前行居中放大，上下行渐隐
- 逐字模式：当前行内按字高亮（依 `LyricDocument.lines[i].words` 计算进度）
- 有翻译/罗马音时：翻译在原文下方小字；罗马音在原文上方小字
- 点击任意行 → seek 到该行起始时间
- 无歌词时：显示"暂无歌词"+（依能力位）"在线匹配"入口

### 2.2 进度条交互
- 拖动时预览时间气泡，松开才 seek（避免频繁 seek）
- 缓冲进度用浅色叠加显示 `EngineSnapshot.buffered`
- 加载中（`processing==loading/buffering`）时进度条禁用拖动，显示不确定态动画

### 2.3 播放失败的呈现
播放失败时**不弹阻塞式对话框**，而是在歌曲名下方显示一行错误提示 + "重试"按钮 + "换源播放"按钮。

- 触发条件：`_retryAfterSourceFailure` 被设置（见施工文档 §3.1）
- "重试"：重新调用当前源的 `musicUrl`
- "换源播放"：依 `name + artists` 在所有已启用源中搜索同曲，列出候选供选择
- 错误原文写入诊断日志，UI 只显示友好文案（如"该音源暂时不可用"）

### 2.4 外观选项（设置 → 外观）
| 项 | 选项 | 默认 |
|---|---|---|
| 主题模式 | 浅色 / 深色 / 跟随系统 | 跟随系统 |
| 动态取色 | 开 / 关 | 开（从封面提取主色） |
| 自定义主题色 | 色板 | 无 |
| 封面形状 | 方形 / 圆形 | 方形 |
| 歌词字号 | 滑块 | 中 |
| 播放页背景 | 纯色 / 封面模糊 | 封面模糊 |
| 动画强度 | 完整 / 精简 / 关闭（无障碍） | 完整 |

## 3. 搜索页

### 3.1 布局与流程

```
┌───────────────────────────────┐
│ 🔍 输入关键词...        [搜索] │
│ 源: [全部▾] [酷我] [插件A] ... │  ← 源筛选 chips（仅列声明 searchMusic 的源）
├───────────────────────────────┤
│ 正在从 3 个源搜索…             │  ← 进度提示（渐进式）
├───────────────────────────────┤
│ ▸ 酷我 (12)                    │  ← 按源分组的折叠区
│   歌曲 · 专辑 · 歌手 tabs       │
│   ○ 歌名 - 歌手                │
│   ○ ...                        │
│ ▸ 插件A (8)                    │
│   ...                          │
└───────────────────────────────┘
```

**规则**：
- **扇出**：只对"已启用 + 声明 `searchMusic`"的源发起请求，每源独立超时 10s
- **渐进式**：哪个源先返回就先渲染该分组，不等全部完成
- **分组而非合并**：默认按源分组展示（见 ADR-004 关联的 §4.6 设计），不做跨源合并
- 单源失败：该分组显示"该源无响应"+ 重试按钮，**不影响其他分组**
- 分组内二级 tab（歌曲/专辑/歌手）：**依该源的能力位**决定显示哪些 tab
- 分页：每源独立"加载更多"

### 3.2 搜索结果项
| 字段 | 说明 |
|---|---|
| 歌名 | 主文本 |
| 歌手 | 副文本（多歌手用 ` / ` 连接） |
| 专辑 | 次副文本（可选显示） |
| 时长 | 右侧 |
| 源标识 | 小徽标（区分同名歌曲来自不同源） |
| 音质 | 若源声明多音质，显示最高可用音质标记 |

**点击行为**：直接播放（不弹菜单）；长按/右键 → 菜单（播放、下一首播放、加入歌单、下载、查看来源信息）

### 3.3 空态与错误态
- 无关键词：显示搜索历史（可清除）+ 热门搜索（可选）
- 全部源失败：显示"所有源都无响应"，附"检查源状态"链接跳源管理
- 无结果：显示"未找到结果"+ 提示"换关键词或启用更多源"

## 4. 发现页

**完全依能力位渲染**：只展示"已启用且声明对应能力"的源所提供的榜单/推荐。

```
┌──────────────────────────────┐
│ 排行榜                        │
│  ┌──────┐ ┌──────┐ ┌──────┐  │  ← 来自声明 topList 的源
│  │酷我  │ │插件A │ │ ...  │  │
│  └──────┘ └──────┘ └──────┘  │
├──────────────────────────────┤
│ 推荐歌单                      │
│  ...                          │
└──────────────────────────────┘
```

- 若**没有任何源声明 topList/推荐能力**：整页替换为引导页——"尚未启用可用音源，前往源管理添加"（这是 lx 脚本-only 用户的典型首屏）
- 榜单详情页：歌曲列表，点击即播

## 5. 源管理页（重点）

### 5.1 列表

```
┌────────────────────────────────────┐
│ ● 酷我-增强版        v2.1  [启用 ⏻] │
│   类型: lx 脚本 · 能力: 仅播放       │  ← 能力位直白展示
│   状态: 健康 · 最后检测 2 分钟前     │
│   [详情] [重新检测] [删除]           │
├────────────────────────────────────┤
│ ● 某插件             v1.0  [启用 ⏻] │
│   类型: MusicFree 插件               │
│   能力: 搜索 专辑 歌词 封面          │
│   状态: 降级(3 次失败) · 查看日志    │
└────────────────────────────────────┘
```

**必须呈现的信息**：
- 源名称、版本、类型（lx 脚本 / MusicFree 插件）
- **能力列表**（用人类可读词：搜索/专辑/歌手/歌单/播放/歌词/封面/榜单）
- 健康状态：健康 / 降级 / 失效 / 未知（颜色区分，见 §5.4）
- 最后检测时间

**操作**：启用/禁用开关、详情、重新检测、删除（二次确认）

### 5.2 导入源

**入口**：源管理页 FAB → 菜单（从文件导入 / 从剪贴板导入 / 从 URL 导入）

流程：
1. 读取脚本内容 → 校验编码 UTF-8
2. 解析头部注释（`@name/@description/@version/@author/@homepage`）
3. **执行初始化**（等待 `inited` 事件，超时 15s）
4. 展示"预览确认"面板：源名称、能力列表、支持的音质、是否含用户变量（MusicFree）
5. 用户确认 → 落库 → 列表出现

**失败处理**：初始化失败时展示错误 + 诊断日志（含脚本报错行号），提供"仍然导入（禁用状态）"选项以便用户排查。

### 5.3 源详情
- 头部元信息全字段
- 能力矩阵表
- 用户变量（MusicFree）：可编辑表单，敏感项用 secure storage
- 诊断区：最近 100 条日志（可清空、可导出）
- 危险区：删除源

### 5.4 健康状态视觉
| 状态 | 颜色 | 文案 | 允许操作 |
|---|---|---|---|
| 健康 | 绿 | 健康 | 全部 |
| 降级 | 黄 | 可能不稳定（连续 N 次失败） | 全部，搜索时该源置后 |
| 失效 | 红 | 无法初始化 | 禁用开关仍可用，不参与搜索 |
| 未知 | 灰 | 尚未检测 | 可手动检测 |

## 6. 歌单与本地库

### 6.1 歌单
- 列表页：网格或列表（可切换）；显示封面、名称、曲目数
- 详情页：曲目列表，支持拖拽排序（桌面端拖拽 + 移动端长按拖拽）
- 操作：重命名、改封面、删除、导出（JSON）、导入
- **歌曲来源混合**：同一歌单可混有来自不同源的歌曲；每首歌记住自己的 `sourceKey`，播放时回该源取 URL

### 6.2 本地库
- 入口：音乐页 → 本地
- 扫描：选择目录 → 递归扫描支持的扩展名 → 用 `audio_metadata_reader` 读标签（在 isolate 中执行，避免卡 UI）
- 扫描进度：进度条 + 已发现数量 + 当前文件（可取消）
- 列表：可按名称/歌手/专辑/时长/添加时间排序；支持搜索
- 操作：播放、加入歌单、写回标签（歌名/歌手/专辑/封面/歌词）、在文件管理器中显示
- **无本地权限时**：显示引导（Android 需 `READ_MEDIA_AUDIO`；桌面端首次选择目录时授权）

## 7. 下载页

```
┌─────────────────────────────────┐
│ [下载中 2] [已完成 15] [失败 1]  │
├─────────────────────────────────┤
│ 歌名 - 歌手                      │
│ ▓▓▓▓▓▓░░░░░  62%  1.2MB/s       │
│ 320k · 剩余 00:12   [暂停] [×]   │
└─────────────────────────────────┘
```

- 任务状态：排队中 / 下载中 / 已暂停 / 已完成 / 失败
- 失败项显示原因 + 重试按钮（URL 过期会自动重新取链接后重试，见 §6 施工文档）
- 已完成项：显示文件路径、可"打开所在文件夹"、"写回标签"
- 全局设置：并发数（1-5，默认 3）、下载目录、完成后是否自动写标签、命名模板

## 8. 设置页结构

```
设置
├── 外观（§2.4）
├── 播放
│   ├── 音质偏好（128k/320k/flac/flac24bit）
│   ├── 允许与其他应用混音（移动端）
│   ├── 耳机拔出时暂停（移动端）
│   └── 播放失败自动换源（开/关）
├── 下载（§7）
├── 歌词
│   ├── 歌词来源优先级
│   ├── 字体大小 / 对齐
│   └── 桌面歌词（仅桌面：开关、置顶、锁定、字号、颜色）
├── 源管理（§5）
├── 网络（超时、代理、自定义 UA）
├── 快捷键（仅桌面，应用内：Space/←→/↑↓/Enter）
├── 存储（缓存大小、清理）
└── 关于（版本、许可清单、日志导出、诊断信息）
```

**许可清单页**：必须列出所用开源库及其许可证（`flutter_show_licenses` 或自建列表）。

## 9. 桌面特有交互

| 能力 | 规格 |
|---|---|
| 窗口 | 可缩放、记忆尺寸与位置；关闭按钮行为可配置（退出 / 最小化到托盘） |
| 托盘 | 图标 + 菜单（播放/暂停、上一首、下一首、显示主窗口、退出） |
| 应用内快捷键 | `Space` 播放/暂停、`←/→` 快退/快进 5s、`↑/↓` 音量、`Enter` 播放选中项；输入框聚焦时不拦截。全局自定义快捷键已延后（媒体键经系统媒体层天然可用） |
| 桌面歌词窗 | 独立无边框窗口，置顶，可拖动；水平/竖排切换；锁定后鼠标穿透；跟随主窗口关闭策略可配置 |
| 文件拖放 | 拖入音频文件 → 加入播放队列；拖入 `.js` 脚本 → 导入为源 |
| 右键菜单 | 歌曲项、歌单项、源项均有上下文菜单 |

## 10. 状态与反馈规范（全局）

| 场景 | 呈现 |
|---|---|
| 加载中 | 骨架屏（列表）或不确定态指示器（按钮内） |
| 空态 | 插画/图标 + 一句说明 + 一个明确动作按钮 |
| 错误 | 内联提示条，**不打断操作**；仅"破坏性操作失败"用对话框 |
| 成功 | 轻量 Snackbar（2s），不弹窗 |
| 破坏性操作 | 二次确认对话框，写明后果 |
| 长耗时任务 | 进度可见 + 可取消 + 后台继续 |

**禁止**：用对话框承载常规信息；用 Toast 承载需要用户决策的信息。

## 11. 无障碍与国际化

- 所有交互元素有语义标签（`Semantics`）
- 支持系统字体缩放至 200%，关键布局不溢出
- 动画可关闭（跟随系统"减少动态效果"）
- 文本全部走 `intl`，不硬编码中文字符串；首发 zh-CN + en，预留扩展
- 颜色对比度满足 WCAG AA（动态取色时需校验，不达标则回退到默认色）

## 12. 响应式断点

| 宽度 | 布局 |
|---|---|
| < 600dp | 单列，底部导航 |
| 600–900dp | 双列（列表 + 详情），底部导航或侧栏 |
| > 900dp | 侧栏 + 内容 + 可选右侧队列面板 |

桌面端默认 >900dp 布局；平板自动进入双列。

## 13. 验收清单（UI 部分）

- [ ] 五个一级页面在五端均可达，无平台专属崩溃
- [ ] 播放器：封面/歌词切换、逐字高亮、翻译显示、点击行 seek 均正常
- [ ] 播放失败时展示内联错误 + 重试 + 换源，**无阻塞对话框**
- [ ] 搜索：多源渐进式返回，单源失败不影响其他源
- [ ] 源管理：能力位正确展示；lx 脚本显示"仅播放"；失效源不参与搜索
- [ ] 导入源：失败时能看到错误与日志，可"仍导入为禁用"
- [ ] 歌单可混合多源歌曲且能正确回源播放
- [ ] 本地库扫描在 isolate 执行，扫描时 UI 不卡顿
- [ ] 下载：暂停/恢复/失败重试/URL 过期自动重取
- [ ] 桌面：托盘、应用内快捷键（Space/←→/↑↓）、媒体键、桌面歌词窗、文件拖放均可用
- [ ] 无源时发现页显示引导而非空白
- [ ] 设置页含许可清单；关于页可导出日志
